# Дом, милый хаос

Локальная заготовка подарка на новоселье Юли, Радиона и Локи. Next.js, TypeScript, React Three Fiber. Все модели собраны из простых форм прямо в коде, платных ресурсов нет.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

Открой адрес, который появится в терминале (обычно http://127.0.0.1:3000).

## Где менять

- `lib/questions.ts` — восемь вопросов, ответы и реплики Локи.
- `components/Room.tsx` — комната, мебель, свет, вращение и появление предметов.
- `app/page.tsx` — интро, ход игры, финал. Здесь же условная иллюстрация Локи: её можно заменить фотографией.
- `app/globals.css` — цвета, размеры и мобильная версия.

Выборы сохраняются в этом браузере. Кнопка «Обжить заново» сбрасывает игру. Пропуск добавляет первый вариант ответа и соответствующий предмет. Сейчас предмет определяется номером вопроса; разные ответы меняют текст итоговых пожеланий, но не модель мебели. В финале показаны ответы на вопросы 3, 5 и 8.

Проверка типов: `npm run typecheck`. Сборка: `npm run build`.

Это стартовый прототип, не точная модель квартиры или портрет собаки. Комнату можно вращать и приближать, позиции мебели фиксированы. Шрифт загружается из Google Fonts, при отсутствии сети используется Arial. Публикация не настроена; проект можно импортировать в Vercel как обычное приложение Next.js.
